# Блок семантической сегментации для посадки БПЛА
Блок состоит из автоматического менеджера (manager.py), который управляет запуском Unreal Engine, сбором датасета и обучением нейросетей для семантической сегментации.

**ВАЖНО**: Всегда запускайте скрипты через manager.py, а не через main.py. Менеджер сам устанавливает нужные переменные окружения, генерирует имена папок и следит за перезапуском симулятора Unreal Engine.

## 1. Сбор датасета (Collect)

Собирает RGB, карты глубины и маски сегментации в Unreal Engine. Дрон автоматически спавнится по сетке, меняется погода и время суток.

- Команда:
```python manager.py --mode collect```
- Где настраивать: config.py
- Основные параметры: DATASET_SIZE, полигоны спавна, настройки камеры, частота смены погоды.

## 2. Обучение одной модели (Train)

Запускает стандартное обучение одной конфигурации сети. Папка с результатами создается в runs/segmentation/.

- Команда (Новый запуск):
```python manager.py --mode train```
- Команда (Продолжить прерванное обучение):
```python manager.py --mode train --resume_run Unet_resnet34_12_05_2026_14_00_00```
- Где настраивать: config_train.py (задает дефолтные значения).
- Что сохраняется: Веса (best_model.pth, model_epoch_N.pth), логи TensorBoard, картинки с примерами сегментации и config.json.

## 3. Перебор гиперпараметров (Grid Search)

Запускает серию экспериментов. Автоматически создает папку сессии (например, Search_Session_28_04_2026_12_00_00), сохраняет в нее матрицу перебора и поочередно обучает все возможные комбинации (модели, батч-сайзы, оптимизаторы и т.д.).

- Команда (Новая сессия):
```python manager.py --mode search```
- Команда (Продолжить прерванную сессию):
```python manager.py --mode search --resume_run Search_Session_28_04_2026_12_00_00```
(При возобновлении скрипт прочитает search_config.json из папки сессии и продолжит ровно с того места, где остановился, пропустив завершенные эксперименты).
- Где настраивать: config_tune.py (список словарей SEARCH_GRIDS).

## 4. Очистка датасета (Utils)

Утилита удаляет бракованные снимки и аккуратно сдвинет нумерацию файлов, чтобы не было пропусков в индексах названий.

- Автоматическая очистка (рекомендуется после сбора):
```python utils.py --clean-masks --clean-dark```
- Удалить конкретные кадры вручную:
```python utils.py --delete 10 15 42```

## 5. Просмотр графиков (TensorBoard)
Чтобы сравнить графики метрик и Loss для разных экспериментов:
```tensorboard --logdir runs/segmentation```
